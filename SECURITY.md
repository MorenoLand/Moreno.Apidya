## Security

This is a hobby project that plays a 1992 Amiga game from data files the user supplies. If you find
something that could hurt people running it (for example a crafted disk image that makes the loader
read or write outside the project), please report it privately through GitHub's
[security advisories](https://github.com/MorenoLand/Moreno.Apidya/security/advisories/new)
rather than opening a public issue.

Only the latest version on the main branch is looked after.
