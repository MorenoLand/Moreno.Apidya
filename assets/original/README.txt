Put your own copy of the Apidya disk data here (this folder is git-ignored and hidden from the editor):

  Disk.1
  Disk.2

These are the two disk images of the original game as installed by the WHDLoad package
("Apidya" by Halibut Software / John Girvin, folder ApidyaKaiko/data). You can also leave them anywhere
you like and pick the folder from the in-game start screen, pass --disks=<folder> or set the
APIDYA_DISKS environment variable.

Nothing from the game is stored in this repository.
